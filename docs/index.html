Read the three definitions

Let Z0 be the original seven-port impedance matrix and D = Zmodified − Z0.

‖D‖₂ / ‖Z₀‖₂

The first two use the same full-matrix normalization. The third measures error relative to the original distributed response. All three consider arbitrary complex input combinations at these seven ports, rather than just the input currently animated. A 5% line is a chosen engineering comparison, not a biological boundary.

READING THE MODEL

A soma is one place
to look.

Thinner dendrites carry less material. They also have more axial resistance and less membrane area. Changing one subtree reorganizes these electrical effects differently from thinning the whole arbor.

The explorer solves the passive cable equations in the frequency domain. A sinusoidal input produces a sinusoidal voltage at every compartment, with a location-dependent amplitude and phase. The coloring comes from those calculated node voltages.

(G + iωC) V̂ = Î

G contains axial and membrane conductances; C contains membrane capacitances. The same physical input locations and densities are used for each geometry. Compare the somatic trace with a distal trace, then switch the display to Difference.

The Allen reconstruction retains a measured arbor with its tracing limitations and radius representation. This example tests a specified passive geometry. It does not supply active spikes or a model of ATP consumption.

The separate pulse and local-SWC tool remains available for transient illustrations. Its numerical scope differs from this harmonic explorer; the retained-arbor distal pulse experiment failed its stated temporal accuracy check.
