Explore a local SWC

Your file stays in this browser. Use coordinates and radii in µm, one root, positive radii, and at most 2,500 points.

A single root soma marker is a sphere; cable attachments use child radii. All cable types are passive. Multi-point somata are not supported.

WHAT IS BEING SOLVED?

A small electrical model.
A useful physical intuition.

A current pulse charges membrane capacitance. Current also flows along the cable and leaks across its membrane. Branch dimensions change all three processes, so the voltage you observe depends on both geometry and location.

Ci dVi/dt = Ii − gi(Vi − EL) − ∑j gij(Vi − Vj)

The browser solves a finite-volume cable tree with an implicit timestep and a linear-time tree solver. No external service calculates the responses.

How to read the experiment

01

Start with the baseline

At 100% radius, both responses coincide. Watch the pulse arrive and the voltage return toward rest.

02

Change the allocation

Thin all cables or change only daughter B. Less cable volume does not imply smaller voltage changes at every location.

03

Compare observations

A small root difference can accompany a larger local difference. These displayed traces do not establish equivalence for every possible input.
